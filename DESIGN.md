# Design direction

## Editorial engineering
A graphite portfolio with ivory editorial interludes and a pale botanical green accent. The user delegated direction selection. Considered directions: a paper-based engineering journal, a dark product gallery, and an editorial composition with computational linework. Selected the latter for a distinctive first viewport that still puts role, work, and contact first.

## Tokens
- Background #171916; raised surface #1e211c; main text #f0f0e8; secondary #a3a79c; accent #d0e6aa; rules #373b32.
- Experience surface #e9e9df; text #242820; secondary #555d4b.
- Geist Sans, locally served by Next font. Geist Mono reserved for actual code/data. Display tracking -0.04em; body line height 1.7. Display 36–96px; body 14–16px; metadata 10–13px.
- Desktop content max 1248px, fluid gutters 56/40/32/20px. Section spacing 112/88/68px. Fine horizontal rules, 3px corners; open rows instead of repeated panels.

## Composition and patterns
- Direct current-role introduction, original hero headline, interactive linework, clear work/contact actions.
- One large project feature followed by two paired features and two compact rows. Abstract project art has no captions or explanatory labels.
- Ivory experience section, current IDT position first. Original senior-design date is retained because its end date is unverified.
- Authentic headshot, concise about copy, education reference, grouped skills, oversized contact close.
- Shared case-study template preserves full problem/build/outcome content and links.

## Interaction and access
- One short, already-visible entrance on the linework. Flow/Orbit/Wave native buttons support keyboard and touch; no continuous animation or scroll hijacking.
- Native anchor navigation, IntersectionObserver active states, menu Escape handling, visible focus, skip links, clipboard success/failure feedback.
- Hover duration 200–250ms, ease cubic-bezier(.16,1,.3,1). Reduced-motion removes animation, transitions, smooth scrolling, and hover scaling.
- All meaningful content server-renders without animation gates; client islands contain only navigation, linework selection, and copy action.

## Reference observations
- https://rauno.me: focused personal introduction and a compact set of craft/project destinations.
- https://linear.app: hierarchical product narrative and progressive presentation of complexity.
- https://www.joshwcomeau.com: approachable explanations and interactive frontend subject matter.
- https://brittanychiang.com: immediately readable role, experience, technologies, and project evidence.
These informed principles; no source code, brand assets, or entire compositions were copied. REA and the requested Vercel skills were not installed. Impeccable and UI/UX Pro Max informed the design and accessibility checks.

## Content gaps
No résumé file exists, so use an honest “Request résumé” mail link. Do not invent IDT responsibilities, graduation completion, senior design end date, or new project metrics. Metadata removes the old example domain and missing OG image reference.

## Copy preferences
Retain original headlines and factual wording. Use direct, personal language. Avoid slogans, statements about caring or purpose, decorative captions, redundant labels, and footer taglines. StudyGuider is a personal side project used for exams and studying while at school; do not describe it as in progress or imply an ongoing product launch.
